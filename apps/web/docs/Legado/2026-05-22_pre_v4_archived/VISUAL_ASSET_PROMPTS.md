# Visual Asset Prompts

Use estes prompts para gerar imagens raster futuras. Elas devem substituir os SVGs locais sem mudar a arquitetura de componentes.

## Regras gerais

- Sem texto, marcas, logos falsos ou watermark.
- Proporcao limpa para UI, com areas de respiro para titulo/CTA.
- Paleta ATP: navy escuro, verde profundo, branco/off-white, acento lime de bola.
- Sensacao: esporte premium, clube, comunidade, competicao, quadra iluminada.
- Evitar imagem stock generica com blur excessivo.
- Evitar rostos muito reconheciveis quando nao houver pessoa real do usuario.
- Exportar em WebP/AVIF quando possivel, com fallback PNG.
